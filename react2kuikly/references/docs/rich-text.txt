检索信息：RichText组件

RichText组件基础信息：
1. RichText继承自TextView组件，支持所有Text组件的属性
2. 核心功能是通过Span/ImageSpan/PlaceholderSpan方法组合富文本内容

完整示例代码：
```kotlin
RichText {
 // 文本片段
 Span {
 text(\"红色文字\")
 color(Color.RED)
 fontSize(16f)
 }
 
 // 图片片段
 ImageSpan {
 size(40f, 40f)
 src(\"https://example.com/image.png\")
 borderRadius(5f)
 }
 
 // 占位区域
 PlaceholderSpan {
 placeholderSize(80f, 80f)
 spanFrameDidChanged { frame ->
 // 获取占位区域坐标和尺寸
 val (x, y, width, height) = frame
 }
 }
}
```

注意事项：
1. PlaceholderSpan需要配合绝对定位的View实现复杂布局
2. ImageSpan支持所有Image组件的属性设置
3. 可通过组合不同Span实现图文混排效果
4. 占位区域的坐标需要通过spanFrameDidChanged事件动态获取
