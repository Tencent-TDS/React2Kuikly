【Button组件】


依赖引入：import com.tencent.kuikly.core.views.compose.Button

支持所有基础属性，此外还包含如下属性：
1. titleAttr - 设置文本属性（支持链式调用）
 ```kotlin
 titleAttr { 
 text("按钮文字")
 color(Color.RED)
 fontSize(16f)
 }
 ```

2. imageAttr - 设置图标属性
 ```kotlin
 imageAttr {
 src("icon_arrow")
 size(20f, 20f)
 }
 ```

3. highlightBackgroundColor - 按下态背景色
 ```kotlin
 highlightBackgroundColor(Color(0x33000000))
 ```

4. flexDirection - 图文排列方向
 ```kotlin
 flexDirection(FlexDirection.ROW_REVERSE) // 图标在文字右侧

完整示例代码：
```kotlin
Button {
 attr {
 size(200f, 48f)
 backgroundColor(Color.BLUE)
 borderRadius(24f)
 
 titleAttr {
 text(\"带图标的按钮\")
 color(Color.WHITE)
 fontSize(16f)
 }
 
 imageAttr {
 src("ic_arrow_right")
 size(24f, 24f)
 }
 
 flexDirection(FlexDirection.ROW)
 highlightBackgroundColor(Color(0x33000000))
 }
 
 event {
 click {
 // 处理点击事件
 }
 }
}
```

注意事项：
1. 按钮同时设置titleAttr和imageAttr时，默认图标在文字左侧
2. 通过flexDirection可自由调整图文排列方向
3. 按下态颜色建议使用带透明度的颜色值
4. 按钮尺寸建议通过size()方法统一设置
5. 圆角效果需配合borderRadius()使用
