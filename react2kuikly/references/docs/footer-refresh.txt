【FooterRefresh组件】
依赖引入：import com.tencent.kuikly.core.views.FooterRefresh

基础信息：
1. 功能特性：
- 用于在ListView中实现尾部刷新功能
- 支持预加载触发、状态管理、失败重试等特性

2. 核心属性：
┌──────────────────┬────────────────────────────┬──────────┐
│ 属性名 │ 描述 │ 类型 │
├──────────────────┼────────────────────────────┼──────────┤
│ preloadDistance │ 触发加载的底部距离阈值 │ Float │
│ minContentWidth │ 内容区域最小宽度 │ Float │
│ minContentHeight │ 内容区域最小高度 │ Float │
└──────────────────┴────────────────────────────┴──────────┘

3. 状态管理：
┌──────────────────┬────────────────────────────┐
│ 状态枚举 │ 描述 │
├──────────────────┼────────────────────────────┤
│ IDLE │ 空闲状态 │
│ REFRESHING │ 正在刷新 │
│ NONE_MORE_DATA │ 无更多数据 │
│ FAILURE │ 加载失败(展示重试按钮) │
└──────────────────┴────────────────────────────┘

4. 核心方法：
┌──────────────────┬───────────────────────────────┐
│ 方法名 │ 功能说明 │
├──────────────────┼───────────────────────────────┤
│ beginRefresh() │ 手动触发刷新 │
│ endRefresh() │ 结束刷新(带结束状态参数) │
│ resetRefreshState│ 重置到指定状态 │
└──────────────────┴───────────────────────────────┘

完整示例代码片段：
FooterRefresh {
 attr {
 preloadDistance(600f) // 设置600dp触发阈值
 height(60f) // 设置加载视图高度
 }
 event {
 refreshStateDidChange { state ->
 when(state) {
 FooterRefreshState.REFRESHING -> {
 // 执行加载更多逻辑
 }
 FooterRefreshState.FAILURE -> {
 // 显示重试按钮
 }
 }
 }
 click { 
 // 点击重试逻辑
 }
 }
 Text {
 attr { text(\"加载更多...\") }
 }
}

注意事项：
1. 需配合ListView/ScrollView使用
2. 加载完成后必须调用endRefresh()
3. 无更多数据状态需手动设置NONE_MORE_DATA
4. 建议preloadDistance不小于加载视图高度
