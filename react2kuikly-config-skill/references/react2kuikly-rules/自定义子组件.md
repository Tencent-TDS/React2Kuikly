# 自定义子组件

React Native 页面中常见的业务是自定义可复用子组件。转码到 Kuikly 时，自定义组件统一映射为 Kuikly 的 `ComposeView`（组合组件）。

## React Native 自定义组件形态

### 1. Class 组件（本测试工程采用）

```jsx
import React, { Component } from 'react';
import { View, Text } from 'react-native';

export default class ItemView extends Component {
    constructor(props) {
        super(props);
        this.state = { selected: false };
    }
    render() {
        const { title } = this.props;
        return (
            <View style={{ flexDirection: 'row', alignItems: 'center' }}>
                <Text style={{ fontSize: 15 }}>{title}</Text>
            </View>
        );
    }
}
```

### 2. Function 组件 + props

```jsx
import React from 'react';
import { View, Text } from 'react-native';

export default function ItemView({ title, onPress }) {
    return (
        <View>
            <Text onPress={onPress}>{title}</Text>
        </View>
    );
}
```

## Kuikly 映射要点

- React Native 的 `class ItemView extends Component` + `render()` → Kuikly 的 `class ItemView : ComposeView<ItemAttr, ItemEvent>()` + `override fun body()`
- `this.props.xxx` / 函数组件参数 → Kuikly 的 `ctx.attr.xxx`（通过 `ComposeAttr` 子类定义）
- `this.state.xxx` 中需要驱动 UI 更新的状态 → Kuikly 的 `by observable(...)` 响应式属性
- 子组件的点击 / 回调事件 → Kuikly 的 `ComposeEvent`（在 `event { click { ... } }` 中处理）
- 详见 `references/kuikly-example-code.md` 的「组合组件（ComposeView）骨架」
