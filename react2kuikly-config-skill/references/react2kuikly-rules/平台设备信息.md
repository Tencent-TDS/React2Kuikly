# 平台设备信息

## 平台判断

### Android 平台

**React Native 实现**
```javascript
Platform.OS == 'android'
```

**Kuikly 实现**
```kotlin
pagerData.isAndroid
```

### iOS 平台

**React Native 实现**
```javascript
Platform.OS == 'ios'
```

**Kuikly 实现**
```kotlin
pagerData.isIOS
```

## 尺寸获取

### 页面尺寸

**React Native 实现**
```javascript
// 获取页面尺寸
Dimensions.get('window').width
Dimensions.get('window').height
```

**Kuikly 实现**
```kotlin
pagerData.pageViewWidth
pagerData.pageViewHeight
```

### 屏幕尺寸

**React Native 实现**
```javascript
// 获取屏幕尺寸
Dimensions.get('screen')
```

**Kuikly 实现**
```kotlin
pagerData.deviceWidth
pagerData.deviceHeight
```

## 状态栏信息

### 状态栏高度

**React Native 实现**
```javascript
import { StatusBar } from 'react-native';
// 状态栏高度（Android 为数字，iOS 可能为 undefined）
const statusBarHeight = StatusBar.currentHeight ?? 0;
```

**Kuikly 实现**
```kotlin
pagerData.statusBarHeight
```

### 顶部栏高度

**React Native 实现**
```javascript
// RN 无直接“顶部栏高度”字段；通常用安全区顶部 inset 近似
import { useSafeAreaInsets } from 'react-native-safe-area-context';
const insets = useSafeAreaInsets();
const topBarHeight = insets.top; // 含状态栏的安全区高度
```

**Kuikly 实现**
```kotlin
pagerData.statusBarHeight + pagerData.navigationBarHeight
```

### 全面屏判断

**React Native 实现**
```javascript
// RN 无直接 isNotch；可通过安全区或屏幕比例判断
import { useSafeAreaInsets } from 'react-native-safe-area-context';
import { Dimensions } from 'react-native';
const insets = useSafeAreaInsets();
const isNotch = insets.top > 20; // 粗略判断（刘海/挖孔屏安全区更大）
```
