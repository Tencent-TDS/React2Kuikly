# 本地存储

## AsyncStorage.getItem

### React Native 实现

```javascript
AsyncStorage.getItem(key).then(res => {
    // 处理结果
})
```

### Kuikly 实现

Template 项目提供两种本地存储方式：

#### 方式一：通过 BridgeModule（异步/同步）

```kotlin
import com.tencent.template.base.bridgeModule

// 异步读取
bridgeModule.fetchCachedFromNative(key) { response ->
    val value = response?.optString("value", "")
    // 处理结果
}

// 同步读取
val value = bridgeModule.getCachedFromNative(key)
```

#### 方式二：通过 SharedPreferencesModule

```kotlin
import com.tencent.kuikly.core.module.SharedPreferencesModule

val sp = acquireModule<SharedPreferencesModule>(SharedPreferencesModule.MODULE_NAME)
val value = sp.getItem(key)
```

## AsyncStorage.setItem

### React Native 实现

```javascript
AsyncStorage.setItem(key, value)
```

### Kuikly 实现

#### 方式一：通过 BridgeModule

```kotlin
bridgeModule.setCachedToNative(key, value) { response ->
    // 可选回调
}
```

#### 方式二：通过 SharedPreferencesModule

```kotlin
val sp = acquireModule<SharedPreferencesModule>(SharedPreferencesModule.MODULE_NAME)
sp.setItem(key, value)
```
