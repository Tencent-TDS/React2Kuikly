# 基础业务逻辑

## 网络请求

### React Native 实现

```javascript
// 通用网络请求
fetch(url, options).then(res => {
    // 处理结果
})
```

### Kuikly 实现

Template 项目通过 `BridgeModule` 的 `ssoRequest` 方法发起网络请求：

```kotlin
import com.tencent.template.base.bridgeModule
import com.tencent.kuikly.core.nvi.serialization.json.JSONObject

// 异步方式
val reqParams = JSONObject().apply {
    put("key", "value")
}
bridgeModule.ssoRequest("cmd_name", reqParams) { response ->
    // response 为 JSONObject?
    val code = response?.optInt("code")
    val data = response?.optJSONObject("data")
    // 处理响应...
}

// 协程方式（suspend）
val result = bridgeModule.ssoRequest("cmd_name", reqParams)
// result 为 JSONObject?
```

## 数据上报

### React Native 实现

```javascript

```

### Kuikly 实现

```kotlin
import com.tencent.template.base.bridgeModule

// 灯塔上报
bridgeModule.reportDT("eventCode", JSONObject().apply {
    put("key", "value")
})

// 实时上报
bridgeModule.reportRealTime("eventCode", JSONObject().apply {
    put("key", "value")
})
```

## 获取页面参数

### React Native 实现

```javascript
const paramValue = this.props.paramName || ''
```

### Kuikly 实现

```kotlin
// 通过 pageData.params 获取页面参数
val paramValue = pageData.params.optString("paramName", "")
val paramInt = pageData.params.optInt("paramName", 0)
val paramBool = pageData.params.optBoolean("paramName", false)
```

## 打开页面

### React Native 实现

```javascript
// 打开新页面（react-navigation）
navigation.navigate('PageName', { key: 'value' })
```

### Kuikly 实现

```kotlin
import com.tencent.kuikly.core.module.RouterModule

// 方式一：通过 RouterModule
acquireModule<RouterModule>(RouterModule.MODULE_NAME).openPage(pageName, pageData)

// 方式二：通过 BridgeModule
bridgeModule.openPage(url, closeCurPage = false, closeSamePage = false, userData = JSONObject())
```

## 样式转化

React Native 中的样式数值在转化为 Kuikly 时使用 `Float` 值：

### React Native 样式

```javascript
{
    marginRight: 16,
    width: 60,
    height: 60,
    borderRadius: 8,
}
```

### Kuikly 样式

```kotlin
View {
    attr {
        marginRight(16f)
        width(60f)
        height(60f)
        borderRadius(8f)
    }
}
```

## 夜间模式

Template 项目通过 `BasePager.isNightMode()` 判断是否为夜间模式：

```kotlin
// 判断夜间模式
if (isNightMode()) {
    // 夜间模式样式
    backgroundColor(Color(0xFF1A1A1A))
} else {
    // 日间模式样式
    backgroundColor(Color.WHITE)
}
```
