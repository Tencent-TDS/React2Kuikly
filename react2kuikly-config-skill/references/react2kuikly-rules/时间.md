# 时间处理

## 概述

**React Native**: 使用 JavaScript 的 `Date` 对象  
**Kuikly**: Template 项目通过 `BridgeModule` 提供时间相关方法，也可使用 `CalendarModule`

## BridgeModule 时间方法

### 获取当前时间戳

**React Native 实现**
```javascript
Date.now()
new Date().getTime()
```

**Kuikly 实现**
```kotlin
import com.tencent.template.base.bridgeModule

// 同步获取时间戳（毫秒）
val timestamp = bridgeModule.currentTimeStamp()
```

### 获取服务器时间

**React Native 实现**
```javascript
// 通过接口获取服务器时间
```

**Kuikly 实现**
```kotlin
// 异步获取
bridgeModule.localServeTime { response ->
    val serverTime = response?.optLong("timestamp")
}

// 协程方式
val result = bridgeModule.localServeTime()
val serverTime = result?.optLong("timestamp")
```

### 日期格式化

**React Native 实现**
```javascript
const date = new Date(timestamp)
const formatted = `${date.getFullYear()}-${date.getMonth()+1}-${date.getDate()}`
```

**Kuikly 实现**
```kotlin
// 通过 BridgeModule 同步格式化
val formatted = bridgeModule.dateFormatter(timestamp, "yyyy-MM-dd HH:mm:ss")
```

## CalendarModule 方法

### 1. formatTime（时间戳格式化）

**功能**: 将毫秒级时间戳转换为自定义格式的时间字符串。

**参数**:
- `timeMillis`: 需格式化的时间戳，单位为毫秒，类型为 `Long`
- `format`: 时间格式模板，类型为 `String`，示例：`"yyyy-MM-dd HH:mm:ss.SSS"`

### 2. parseFormattedTime（时间字符串转时间戳）

**功能**: 将符合指定格式的时间字符串，转换为毫秒级时间戳。

**参数**:
- `formattedTime`: 待转换的格式化时间字符串，类型为 `String`
- `format`: 与时间字符串匹配的格式模板，类型为 `String`

### 3. newCalendarInstance（获取 Calendar 实例）

**功能**: 根据传入的时间戳生成对应的 Calendar 实例；若时间戳为 0，则返回当前时间的 Calendar 实例。

**参数**: 
- `timeMillis`: 作为基准的时间戳，单位为毫秒，类型为 `Long`

## Calendar 实例方法

### set

**功能**: 设置日期某一字段的值。

**参数**: 
- `field`: 日期域（如年、月、日、时等），类型为 `ICalendar.Field`
- `value`: 需设置的字段值，类型为 `Int`

### add

**功能**: 对日期某一字段的值进行增减。

**参数**: 
- `field`: 日期域，类型为 `ICalendar.Field`
- `value`: 需增减的数值，类型为 `Int`

### get

**功能**: 获取日期某一字段的当前值。

**参数**: 
- `field`: 日期域，类型为 `ICalendar.Field`

**返回值**: 类型为 `Int`

### timeInMillis

**功能**: 将当前 Calendar 实例转换为毫秒级时间戳。

**参数**: 无参数

**返回值**: 类型为 `Long`
